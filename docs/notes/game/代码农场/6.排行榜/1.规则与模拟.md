# 规则与模拟

## 排行榜运行方式

使用 `leaderboard_run(leaderboard, filename, speedup)` 启动排行榜模拟

排行榜不会直接使用当前存档状态，每个分类都有固定的初始解锁、资源和完成条件，因此同一份代码可以反复测试

## 初始条件与完成条件

- 不同榜单的初始资源和目标不同
- 达成目标后程序不会自动停止，需要主动结束程序才算完成
- 程序结束时未满足目标则本次运行失败
- Fastest Reset 从单格农场和空解锁开始，目标是重新解锁排行榜

## 模拟、随机种子与计时

排行榜会通过重复运行降低随机差异，最终按多次运行的平均时间记录成绩

开发阶段可以先使用普通 `simulate()` 固定种子调试，确认逻辑稳定后再运行排行榜

## 提交前检查

- [ ] 达到目标后可以正常退出
- [ ] 不依赖当前存档中的全局变量或资源
- [ ] 随机情况下不会卡死
- [ ] 记录使用的游戏版本和代码版本
