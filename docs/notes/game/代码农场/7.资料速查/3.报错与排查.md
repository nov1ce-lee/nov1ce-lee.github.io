# 报错与排查

## 语法与缩进

游戏使用 Python 风格语法，但不是完整 Python

- `IndentationError`：同一层代码的缩进不一致，统一使用空格
- `SyntaxError`：括号、冒号、引号或函数调用格式有问题
- `NameError`：变量或函数名没有定义，也可能是拼写大小写不一致
- `TypeError`：把返回值类型用错，例如对 `None` 做解包

先用一小段代码确认语法，再逐步把函数拼回主程序

```python
def test():
    quick_print("test")


test()
```

## 运行时错误

### `plant()` 没有种上

按顺序检查

1. 当前地面是否为 `Grounds.Soil`
2. 背包里是否有对应资源
3. 当前格是否已有实体
4. 实体是否已经解锁

```python
if get_ground_type() != Grounds.Soil:
    till()

if not plant(Entities.Carrot):
    quick_print("plant failed", get_pos_x(), get_pos_y())
```

### `harvest()` 结果不对

`harvest()` 对不可收获实体也会执行尝试，先判断类型和成熟状态

```python
if get_entity_type() is not None and can_harvest():
    harvest()
```

### `measure()` 得到 `None`

`measure()` 不是通用的坐标或数值查询

- 向日葵：花瓣数量
- 仙人掌：大小
- 宝藏、苹果：下一个目标位置
- 南瓜：内部编号，不等于南瓜大小
- 其他实体：通常为 `None`

## 死循环与递归

`while True` 适合农场常驻脚本，排行榜和模拟任务必须有结束条件

```python
while num_items(Items.Pumpkin) < 200000000:
    farm_pumpkin()
```

递归函数要保证每次调用都更接近结束条件，不要用递归代替普通遍历

## 无人机卡住

### `spawn_drone()` 返回 `None`

当前无人机数量达到上限时不会生成新无人机

```python
drone = spawn_drone(worker)
if drone is not None:
    wait_for(drone)
```

### `wait_for()` 没有返回

确认传入的是 `spawn_drone()` 返回的句柄，而不是任务函数本身

```python
handle = spawn_drone(worker)
if handle is not None:
    result = wait_for(handle)
```

### 多架无人机互相覆盖

常见原因是两个任务处理了重叠区域，或多个无人机共用同一个目标列表

- 给每架无人机分配不重叠的坐标范围
- 子无人机启动前保存自己的起点
- 通过 `wait_for()` 明确阶段边界
- 不要假设无人机生成后会自动排队

## 结果不稳定

### 移动方向和边界

普通农场边界会环绕，使用 `move()` 时走多一步可能回到另一侧

```python
for _ in range(get_world_size()):
    move(East)
```

迷宫中要先用 `can_move(direction)`，不能把普通农场的移动逻辑直接复用过去

### 作物成熟时间

不同作物、浇水状态、肥料和相邻条件都会影响等待时间，不要用固定 `sleep` 思路判断成熟

统一使用 `can_harvest()`，需要统计时记录 `get_tick_count()` 或 `get_time()`

### 排行榜没有成绩

- 是否调用了正确的 `Leaderboards.*`
- 是否达成了该榜单的资源数量
- 程序是否在达成目标后结束
- 是否误用了普通农场的初始资源假设

## 性能排查顺序

1. 用 `get_tick_count()` 找出耗时最多的函数
2. 减少成功的 `move()`、`plant()`、`harvest()` 和 `swap()`
3. 把重复的查询结果缓存到局部变量
4. 确认多无人机没有重复劳动
5. 最后再调整路径细节
