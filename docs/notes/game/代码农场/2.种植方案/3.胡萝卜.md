# 胡萝卜

<img src="https://shared.fastly.steamstatic.com/community_assets/images/apps/2060160/e9e333d239e1707ee464dcd907b5b272f28bdb3b.jpg" width="96" height="96" alt="胡萝卜成就图标">

## 作物机制

- 实体：`Entities.Carrot`
- 产物：`Items.Carrot`
- 必须种在 `Grounds.Soil` 上，地面不对时需要先调用 `till()`
- 种植会消耗木材和干草，实际数量用 `get_cost(Entities.Carrot)` 查询
- 支持混合种植，可以用 `get_companion()` 获取伴生需求

胡萝卜是第一种需要处理地面和种植成本的作物，也是南瓜、向日葵等后续内容的重要资源
