# 向日葵

<img src="https://shared.fastly.steamstatic.com/community_assets/images/apps/2060160/d025da86ce1b94bad83e1183f0bc4f71f2453ab9.jpg" width="96" height="96" alt="向日葵成就图标">

## 作物机制

- 实体：`Entities.Sunflower`
- 产物：`Items.Power`
- 需要种在土壤上
- `measure()` 会返回当前向日葵的花瓣数量，范围为 `7 ~ 15`
- 农场里至少有 10 棵向日葵时，收获当前花瓣数最多的一棵可以获得 `8` 倍能量
- 如果先收获了不是最大花瓣数的向日葵，下一次收获也只能获得普通产量

能量存在时，无人机移动、种植和收获等操作会以两倍速度执行，因此向日葵不仅是资源作物，也会影响其他自动化方案的运行速度
