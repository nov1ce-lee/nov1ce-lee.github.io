# 灌木与树木

<img src="https://shared.fastly.steamstatic.com/community_assets/images/apps/2060160/c6366bdf337b3e48e5b6a92d181479cfacffaa68.jpg" width="96" height="96" alt="木材专业户成就图标">

## 作物机制

灌木和树都会产出 `Items.Wood`，两者都可以种在草地或土壤上

### 灌木

- 实体：`Entities.Bush`
- 生长较快，单次木材产量低于树
- 使用 `Items.Weird_Substance` 可以将灌木变成迷宫
- 支持混合种植加成

### 树

- 实体：`Entities.Tree`
- 基础产量高于灌木，但生长时间更长
- 上下左右每相邻一棵树，生长时间都会再次翻倍
- 直接铺满整片农场会让每棵树受到四个方向的影响，通常需要交错种植
- 支持混合种植加成

## 优化方向

- 比较纯灌木、纯树和交错布局
- 平衡单次产量与等待时间
- 避免相邻树木拖慢整轮收获
