# 草与干草

<img src="https://shared.fastly.steamstatic.com/community_assets/images/apps/2060160/eda73be1f02fdf9f7da568a0dd71f20c72aced43.jpg" width="96" height="96" alt="干草专业户成就图标">

## 作物机制

- 实体：`Entities.Grass`
- 产物：`Items.Hay`
- 草会在 `Grounds.Grassland` 上自动生长，不需要主动播种
- 收获后地面仍然是草地，等待下一批草长出来即可
- 干草是开局最早获得的资源，用于解锁循环、移动和种植等基础能力
- 解锁混合种植后，草也可以通过对应的伴生植物提高产量

草的生长速度很快，前期只需要不断收获，农场扩建后再加入遍历逻辑
