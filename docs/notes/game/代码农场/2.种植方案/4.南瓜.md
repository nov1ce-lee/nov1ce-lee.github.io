# 南瓜

<img src="https://shared.fastly.steamstatic.com/community_assets/images/apps/2060160/0e05a8d308f35f74ac73c8a7826e5753e28675c4.jpg" width="96" height="96" alt="南瓜成就图标">

## 作物机制

- 实体：`Entities.Pumpkin`
- 产物：`Items.Pumpkin`
- 和胡萝卜一样需要种在土壤上，种植会消耗胡萝卜
- 成熟南瓜相邻并组成完整正方形时会合并成巨型南瓜
- 南瓜成熟时约有 `20%` 概率枯死，枯死后不会产出任何资源
- 对枯死南瓜的位置直接重新 `plant()` 即可，不需要先收获

巨型南瓜的产量会随边长增加，边长达到 `6` 以后才能吃满合并倍率，因此重点不是种完就收，而是检查枯死位置并补种到合并完成
