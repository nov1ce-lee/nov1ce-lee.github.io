# 快速开始

游戏中的无人机不会自己干活，需要在代码窗口里编写程序并运行

前期不用急着写一套完整的农场程序，可以先从下面几个操作开始

- 判断当前作物是否成熟
- 收获当前地块
- 向指定方向移动
- 使用循环重复执行

先把“判断是否可以收获 → 收获 → 移动到下一格”跑起来，再慢慢加入翻地、种植和资源检查

## 整理自己的工具文件

代码变多以后，可以单独写一个 `utils` 文件存放会重复使用的工具函数

例如移动相关的函数可以先规划成下面这些

```python
# 移动到指定坐标
def move_to(x, y):
    pass

# 沿一个方向移动指定距离
def move_steps(direction, steps):
    pass

# 回到农场原点
def move_to_origin():
    pass

# 按固定路线遍历整片农场
def traverse_farm(callback):
    pass
```

这里暂时只定函数用途，等对应功能解锁后再补实现

除了移动，还可以继续整理这些工具

- 检查并切换地面类型
- 检查种植资源是否足够
- 等待作物成熟
- 获取农场尺寸和当前位置
- 按行、按列或按区域遍历农场
- 统计一轮种植使用的时间和产量

通用逻辑放进 `utils`，不同作物只保留自己的种植和收获规则，后面改代码会方便很多
