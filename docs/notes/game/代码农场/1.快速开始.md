# 快速开始

在代码窗口编写程序并运行，无人机会按指令工作；需要修改时先停止程序。出现报错时，根据提示定位对应行即可。

开始阶段只需掌握变量、条件判断、循环和函数。先完成“判断是否可以收获—执行收获—移动到下一格”的循环，再逐步加入种植、资源检查和地块遍历。

接下来可按作物查看[种植方案](/notes/games/code-farm/planting/)，需要复用和优化代码时再看[自动化架构](/notes/games/code-farm/automation/)。函数用法和常见问题集中在[资料速查](/notes/games/code-farm/reference/)。
