# 迷宫与黄金

## 迷宫机制

- 对灌木使用 `Items.Weird_Substance` 可以生成迷宫
- 使用数量和迷宫升级等级会影响迷宫大小，实际计算需要结合 `get_world_size()` 和 `num_unlocked(Unlocks.Mazes)`
- 迷宫中除宝箱外都是 `Entities.Hedge`，无人机不能穿过树篱
- 找到 `Entities.Treasure` 后使用 `harvest()` 可以获得 `Items.Gold`
- 在其他位置错误使用 `harvest()` 会直接让迷宫消失
- `move()` 会返回是否移动成功，也可以用 `can_move()` 提前检查墙壁
- `measure()` 可以返回宝箱坐标

普通迷宫没有环路，可以使用沿墙走等简单方案；重复利用后的迷宫会逐步拆掉部分墙壁并出现环路，需要记录已经访问的位置
