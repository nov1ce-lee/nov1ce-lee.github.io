# 恐龙与骨头

## 恐龙机制

- 使用 `change_hat(Hats.Dinosaur_Hat)` 进入恐龙玩法
- 装备后会自动消耗仙人掌并生成苹果
- 恐龙走到苹果的位置后会吃掉苹果，尾巴长度增加 1，并在随机位置生成下一个苹果
- 对苹果使用 `measure()` 可以获得下一个苹果的坐标
- 恐龙不能穿过农场边界，也不能撞到自己的尾巴，移动失败时 `move()` 返回 `False`
- 苹果准备生成的位置如果已经有其他实体，苹果不会出现，因此开始前需要清理农场
- 换掉恐龙帽时会收获整条尾巴，长度为 `n` 时获得 `n ** 2` 个骨头
- 恐龙帽只有一顶，这部分不能用多架无人机同时刷
