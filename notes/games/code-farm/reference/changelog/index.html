版本更新记录

约 685 字大约 2 分钟

2026-09-23

这里记录会影响脚本、排行榜和本攻略的版本变化

游戏版本

1.0 正式版

正式版带来了多无人机、新的解锁树和完整的排行榜体系，之前按单无人机编写的脚本需要重新考虑分区和同步

重点变化

  • 支持 spawn_drone()、num_drones()、max_drones() 等多无人机接口
  • 增加 Megafarm、Leaderboard 等解锁项
  • 增加单无人机排行榜和普通排行榜
  • 解锁节点、资源和模拟入口重新整理

编辑器与界面更新

官方公告中提到的编辑器相关变化

  • 增加夜间、明亮和自定义颜色主题
  • 支持部分社区翻译
  • 外部编辑器写入的 Python 类型注解会被忽略
  • 自动补全更快识别新变量
  • 大型脚本仍可能让编辑器变慢

API 变化

已确认的接口

下面这些接口来自当前官方 Wiki 清单，适合直接放进脚本

move(direction)
get_pos_x()
get_pos_y()
get_world_size()
get_entity_type()
get_ground_type()
can_harvest()
harvest()
plant(entity)
measure(direction=None)
spawn_drone(task, *args)
wait_for(drone)
leaderboard_run(board, file_name, speedup)

需要注意的变化

  • get_op_count() 已移除，计时改用 get_tick_count()
  • timed_reset() 已移除，排行榜运行改用 leaderboard_run()
  • get_time() 的 tick 成本已调整为 0，适合做时间记录
  • spawn_drone() 支持把额外参数传给任务函数，但仍要处理返回 None 的情况
  • len() 对不支持长度的对象曾导致卡死，遇到异常先确认对象类型
  • 不要依赖旧脚本中通过漏洞共享无人机内存的写法

操作耗时

当前资料中的通用规则

  • 查询类函数通常消耗 1 tick
  • 成功的移动、种植、收获和交换通常消耗 200 ticks
  • 失败的可失败操作通常只消耗 1 tick
  • get_tick_count() 不消耗 tick，get_time() 也适合用于轻量计时

具体数值以当前版本游戏内说明为准，排行榜脚本最好重新实测

攻略调整

2026-10-09

  • 补充 API、常量、操作耗时和多无人机说明
  • 增加移动、种植、测量、资源检查和排行榜代码片段
  • 增加常见运行时错误、无人机同步和排行榜排查
  • 南瓜攻略改为记录 6 × 6 分区、循环补种和两阶段并行
  • 仙人掌攻略补充相邻交换和多无人机排序思路
