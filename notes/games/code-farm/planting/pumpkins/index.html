南瓜

约 1836 字大约 6 分钟

2026-09-23

作物机制

  • 实体：Entities.Pumpkin
  • 产物：Items.Pumpkin
  • 和胡萝卜一样需要种在土壤上，种植会消耗胡萝卜
  • 成熟南瓜相邻并组成完整正方形时会合并成巨型南瓜
  • 南瓜成熟时约有 20% 概率枯死，枯死后不会产出任何资源
  • 对枯死南瓜的位置直接重新 plant() 即可，不需要先收获

巨型南瓜产量

巨型南瓜的产量不是面积，而是边长带来的立方收益

大小产量
1 × 11 × 1 × 1 = 1
2 × 22 × 2 × 2 = 8
3 × 33 × 3 × 3 = 27
4 × 44 × 4 × 4 = 64
5 × 55 × 5 × 5 = 125
n × n，n ≥ 6n × n × 6

边长达到 6 后就能吃满合并倍率，继续扩大只增加占地和等待时间，所以实际种植以 6 × 6 为目标最合适

重点不是种完马上收，而是要将枯死的南瓜进行补种，等整块南瓜合并完成再收获，以实现收益最大化

合并与农场布局

当前方案不直接尝试把整个农场合并成一颗南瓜，而是把农场划分为 4 × 4 = 16 个独立区域

每个区域使用 6 × 6 的南瓜地，区域起点之间相隔 7 格

区域起点：(7 * 列, 7 * 行)
区域大小：6 × 6
区域数量：4 × 4 = 16

每块地之间留一格间隔，避免相邻区域互相合并

每块 6 × 6 的地再沿高度方向分成两个 6 × 3 半区，分别交给两架无人机处理

一架无人机负责调度、等待和最终收获

另一架无人机负责并行种植或检查，只处理自己的半区

最多同时使用 32 架无人机，16 块地各使用两架

自动化方案

这套方案的调整都围绕几个函数展开，外层的 4 × 4 分区和 get_big() 主流程没有大改

先把一块地跑通

先让每架无人机只负责一块 6 × 6 的地，流程保持简单

  1. 种满一块南瓜地
  2. 找出枯死或未成熟的位置
  3. 循环补种和检查，直到整块地都可以收获
  4. 执行 harvest()
from utils import *

set_world_size(27)
pumpkin_size = 6


def get_big():
    pos = (get_pos_x(), get_pos_y())
    while True:
        init_plant(pos)
        check_plant(pos)
        harvest()
        move_to(pos[0], pos[1])


def init_plant(pos):
    for i in range(pumpkin_size):
        for j in range(pumpkin_size):
            get_move(pos, i, j)
            water()
            if get_ground_type() != Grounds.Soil:
                till()
            plant(Entities.Pumpkin)


def check_plant(pos):
    bad_pumpkins = []
    for i in range(pumpkin_size):
        for j in range(pumpkin_size):
            get_move(pos, i, j)
            if not can_harvest():
                bad_pumpkins.append((get_pos_x(), get_pos_y()))
                plant(Entities.Pumpkin)

    while len(bad_pumpkins) > 0:
        pos = bad_pumpkins[len(bad_pumpkins) - 1]
        move_to(pos[0], pos[1])
        if not can_harvest():
            plant(Entities.Pumpkin)
        else:
            bad_pumpkins.remove(pos)


def get_move(pos, i, j):
    pos_x, pos_y = pos
    if i % 2 == 0:
        move_to(pos_x + j, pos_y + i)
    else:
        move_to(pos_x + pumpkin_size - 1 - j, pos_y + i)


clear()
for i in range(4):
    for j in range(4):
        move_to(7 * j, 7 * i)
        if num_drones() < 15:
            spawn_drone(get_big)
        else:
            get_big()

当前的方案，实现了分区、种植、补种和收获的自动化流程，16 个区域各由一架无人机负责

补种循环进行，直到队列清空

单架无人机需要自己完成整块地的种植、检查和补种，速度大约能达到成就要求的三分之二

让补种也并行

初版的 check_plant() 已经能循环补种，这里不改补种规则，只增加一架无人机分担检查和补种

主无人机检查整块 6 × 6，子无人机检查上半区，两边使用同一个补种函数

def check_plant_():
    pos = (get_pos_x(), get_pos_y() + pumpkin_size / 2)
    check_plant(pos, pumpkin_size, pumpkin_size / 2)


finished = spawn_drone(check_plant_)
check_plant(pos, pumpkin_size, pumpkin_size)
wait_for(finished)

这里没有重写 check_plant()，只是让两个无人机同时进入这个方法

坏苗成熟后从 bad_pumpkins 移除，还没成熟就继续 plant()，循环规则和单无人机版本相同

并行检查后，成就完成数量大约提升到五分之四

再调整种植函数

补种逻辑保持不变，瓶颈变成单架无人机需要走完整块 6 × 6 的地

把 init_plant() 拆成两个 6 × 3 半区，主无人机处理下半区，子无人机处理上半区

def init_plant_():
    pos = (get_pos_x(), get_pos_y() + pumpkin_size / 2)
    init_plant(pos)


def init_plant(pos):

            water()
            if get_ground_type() != Grounds.Soil:

get_big() 只需要在种植前后加入无人机调度

finished = spawn_drone(init_plant_)
init_plant(pos)
move_to(pos[0], pos[1])
wait_for(finished)

检查阶段沿用同样的入口函数，主无人机复核整块区域，子无人机并行检查上半区

def check_plant_():
    pos = (get_pos_x(), get_pos_y() + pumpkin_size / 2)
    check_plant(pos, pumpkin_size, pumpkin_size / 2)


finished = spawn_drone(check_plant_)
check_plant(pos, pumpkin_size, pumpkin_size)

组合后的版本

下面是把这些方法组合起来后的版本，外层仍然是 4 × 4 分区，最多使用 32 架无人机

from utils import *

set_world_size(27)
pumpkin_size = 6

def get_big():
    pos = (get_pos_x(), get_pos_y())
    while True:
        finished = spawn_drone(init_plant_)
        init_plant(pos)
        move_to(pos[0], pos[1])
        wait_for(finished)

        finished = spawn_drone(check_plant_)
        check_plant(pos, pumpkin_size, pumpkin_size)
        wait_for(finished)

        harvest()
        move_to(pos[0], pos[1])


def init_plant_():
    pos = (get_pos_x(), get_pos_y() + pumpkin_size / 2)
    init_plant(pos)


def init_plant(pos):
    for i in range(pumpkin_size / 2):
        for j in range(pumpkin_size):
            get_move(pos, i, j)
            water()
            if get_ground_type() != Grounds.Soil:
                till()
            plant(Entities.Pumpkin)


def check_plant_():
    pos = (get_pos_x(), get_pos_y() + pumpkin_size / 2)
    check_plant(pos, pumpkin_size, pumpkin_size / 2)


def check_plant(pos, width, high):
    bad_pumpkins = []
    for i in range(high):
        for j in range(width):
            get_move(pos, i, j)
            if not can_harvest():
                bad_pumpkins.append((get_pos_x(), get_pos_y()))
                plant(Entities.Pumpkin)

    while len(bad_pumpkins) > 0:
        pos = bad_pumpkins[len(bad_pumpkins) - 1]
        move_to(pos[0], pos[1])
        if not can_harvest():
            plant(Entities.Pumpkin)
        else:
            bad_pumpkins.remove(pos)


def get_move(pos, i, j):
    pos_x, pos_y = pos
    if i % 2 == 0:
        move_to(pos_x + j, pos_y + i)
    else:
        move_to(pos_x + pumpkin_size - 1 - j, pos_y + i)


clear()
for i in range(4):
    for j in range(4):
        move_to(7 * j, 7 * i)
        if num_drones() < 31:
            spawn_drone(get_big)
        else:
            get_big()

这个版本的种植和补种都能并行，当前速度可以满足 1 分钟内收获 2000 万南瓜

代码要点

  • get_move() 使用蛇形路线遍历地块，减少每行结束后的回程移动
  • init_plant_() 和 check_plant_() 根据无人机当前位置加上 pumpkin_size / 2，让子无人机定位到上半区
  • 种植阶段使用两个半区并行，检查阶段由主无人机检查整块区域，子无人机并行复核上半区
  • check_plant() 会记录所有不能收获的位置，并持续补种、复查，直到队列清空
  • 外层循环把 16 个区域的起点按 7 格间隔铺开，无人机数量不足时生成新无人机，达到上限后由当前无人机直接处理区域

优化方向

  • 减少对已经成熟南瓜的重复检查
  • 将补种位置按区域分组，避免多架无人机重复处理同一地块
  • 测试不同区域尺寸和间隔对合并速度、移动耗时的影响
  • 在无人机数量不足时增加降级策略，保证单块区域仍能完整收获
