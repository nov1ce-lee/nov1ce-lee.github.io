恐龙与骨头

约 1256 字大约 4 分钟

2026-09-23

恐龙玩法可以看成一个带尾巴的寻路问题，本质上是一个贪吃蛇游戏

控制无人机移动吃掉苹果，尾巴则会占用走过的格子，最后通过换帽一次性收获骨头

恐龙机制

恐龙并不是一种可以直接种植的实体，而是无人机装备恐龙帽后的特殊状态

使用下面的方法装备恐龙帽

change_hat(Hats.Dinosaur_Hat)

只要仙人掌数量足够，游戏就会自动购买一颗苹果并放在无人机下方

无人机移动到苹果所在位置后，再次移动就会吃掉苹果，尾巴长度增加 1，游戏也会尝试购买下一颗苹果并把它放到随机位置

尾巴会拖在无人机后方，占用无人机之前走过的格子

当恐龙帽被换下时，整条尾巴会被收获，并按照尾巴长度的平方转换成骨头

开始前的准备

  • 恐龙帽只有一顶，所以只能让一架无人机参与这套流程
  • 装备后需要有足够的仙人掌，游戏才会自动购买苹果
  • 苹果会随机生成，生成位置如果已经种了其他东西，苹果不会出现
  • 开始前最好清理整片农场，避免苹果因为位置被占用而无法生成

装备恐龙帽后，第一颗苹果会自动放在无人机下方

苹果和尾巴

无人机移动到苹果上方后，再次移动就会吃掉苹果

每吃掉一颗苹果会发生三件事

  1. 尾巴长度增加 1
  2. 如果仙人掌足够，自动购买下一颗苹果
  3. 下一颗苹果随机出现在空闲位置

在苹果位置使用 measure()，可以得到下一颗苹果的坐标

next_x, next_y = measure()

拿到坐标后，可以根据当前无人机位置规划下一段路径，不需要每次都盲目搜索整张地图

尾巴和碰撞

尾巴会填充无人机走过的前一个格子，并跟随无人机向后移动

if not move(direction):
    # 可能撞到了尾巴，也可能已经没有可走的位置

尝试移动到尾巴上时，move() 会失败并返回 False

尾巴最后一节会在移动过程中让开，所以可以移动到刚刚释放的位置

恐龙帽装备期间还有两个限制

  • 不能穿过农场边界绕到另一侧
  • 不能移动到仍被尾巴占用的位置

单次 move() 返回 False 只能说明当前方向走不了，不一定代表恐龙已经长满

只有在已经检查过可用方向，并且所有方向都无法移动时，才能把它当作农场已经被尾巴填满的结束信号

收获骨头

换上其他帽子后，恐龙尾巴会被整体收获

设尾巴长度为 n，得到的骨头数量为

bones=n2\text{bones}=n^2 bones=n2

对应的物品是 Items.Bone

因此恐龙长度越长，最后一次换帽的收益增长越快，重点不是频繁收获，而是尽量让尾巴继续增长

移动耗时

普通情况下，move() 需要 200 ticks

装备恐龙帽后，初始移动耗时变为 400 ticks

每吃掉一颗苹果，移动耗时减少当前值的 3%，减少量向下取整

设吃掉 n 颗苹果后的移动耗时为 T_n，则

T0=400T_0=400 T0​=400

Tn+1=Tn−⌊0.03Tn⌋T_{n+1}=T_n-\lfloor0.03T_n\rfloor Tn+1​=Tn​−⌊0.03Tn​⌋

对应的计算方式可以写成

ticks = 400
ticks -= ticks * 0.03 // 1

这里减少的是 floor(ticks * 0.03)，不是直接把结果四舍五入成整数

自动化思路

可以按下面的顺序逐步实现

  1. 清理农场并确认仙人掌数量足够
  2. 装备恐龙帽，记录无人机当前位置
  3. 使用 measure() 获取苹果坐标
  4. 规划一条不撞尾巴的路径并移动
  5. 吃到苹果后重新获取下一颗苹果的位置
  6. 当所有方向都无法移动时，判断是否已经填满农场
  7. 换掉恐龙帽，收获尾巴并统计骨头

路径规划时要同时维护两个状态

  • 当前苹果的位置
  • 尾巴已经占用的位置

如果只追踪苹果而不记录尾巴，很容易在长尾巴阶段反复撞到自己
